# Accio 渠道

在渠道页选择「添加 → Accio」，明确选择国内版或国际版，再选择「浏览器授权」或「凭据 JSON」。

浏览器授权会打开对应地区的 Accio 官方登录页。同机运行时自动接收回调；ccLoad 部署在远程服务器或容器时，将登录后地址栏中的完整回调 URL 粘贴回弹窗提交即可，即使浏览器显示 localhost 无法连接也可以提交。授权有效期为 5 分钟，可取消后重新开始。成功后自动创建渠道，相同地区与用户再次授权会更新已有渠道凭据。

凭据 JSON 方式支持粘贴内容或选择官方登录凭据文件，也可导入 ccLoad 的标准凭据：

```json
{
  "type": "accio",
  "region": "global",
  "access_token": "你的访问令牌",
  "refresh_token": "你的刷新令牌",
  "expires_at": 1790000000
}
```

`region` 为 `cn` 或 `global`，必须与账号所属地区一致。支持官方 `accessToken`、`refreshToken` 和 `expiresAt` 字段；官方毫秒或 RFC3339 时间归一为 Unix 秒。官方 `utdid` / `deviceId` 保存为设备标识，用于推理请求；缺少时按账号派生稳定标识，已有渠道也可使用。导入时验证账号身份并读取模型目录，相同地区和用户再次导入会更新凭据并保留渠道模型配置。目录批量导入需要凭据带 `type: "accio"` 和 `region`。

凭据包含 `sgcookie` / `sgCookie` 时会一并保存，推理请求自动携带该会话字段，日志中脱敏。刷新或重新导入没有返回该字段时保留原值。

模型列表和上游推理统一使用目录的 `modelName`（如 `claude-haiku-4-5`），同名条目去重，不再生成 `modelCode` 重定向；缺少名称的条目不导入。不再解析或匹配 `modelCode`；不提供猜测的静态模型表。旧渠道若保存了编码名称或编码重定向，需要先清空旧模型行，再点击「获取模型」并保存；重新导入凭据会保留已有模型配置。支持 ccLoad 现有协议转换、流式及非流式、函数工具调用和目录声明支持的图片输入；思考强度按目录能力映射。无法表示的工具控制、严格结构化输出等请求返回能力错误，不静默丢弃约束。

系统提示词（`system` / `developer`）先按大小写敏感的字面规则将 `Claude`、`Codex` 替换为 `Accio`，再复用系统设置 `antigravity_sensitive_words`：对 `system` / `developer` 消息字符串和 text 内容块中的匹配词插入零宽字符，忽略大小写；不改写用户、助手消息、工具声明、参数和结果。设为 `[]` 仅禁用零宽处理，名称替换仍生效；敏感词配置修改后重启生效。正常代理和管理端渠道测试均生效。

访问令牌临期或收到认证失败时自动刷新；没有刷新令牌的账号需要重新导入。额度卡显示上游用量百分比与重置时间，保留订阅原始单位，不把百分比当作积分或美元。Accio 没有接入签到功能。

请求体中的 `session_key`、`conversation_id`、`conversation_name` 会透传给 Accio，支持 Chat、Responses、Anthropic 和 Gemini 入口。也接受 `sessionKey`、`session_id`、`sessionId`、`conversationId`、`conversationName`：同组按上述顺序取首个非空字符串，去除首尾空白后发送原生蛇形字段，非字符串值报错。渠道请求体规则可覆盖或删除这些字段；不会自动从请求头生成会话标识。每次推理仍独立生成 `request_id` 和 `message_id`。

国内版与国际版都连接 `phoenix-gw.alibaba.com`，使用不同地区请求头。推理直接发送 HTTP 请求，不需要运行 Accio 桌面程序。网页登录使用 PKCE 和 state 校验，回调地址在授权与换码时保持一致；凭据只交给自己的 ccLoad 后端，不要放入公共日志或仓库。

实现经过模拟上游的凭据、目录、工具、流终态、刷新和跨协议集成测试。2026-11-07 已在真实国际版账号复现并修复 `accio_gateway_blocked / Bxpunish: 1`：所有请求从 `undici` 改为标准浏览器 UA，使用客户端版本 `0.34.4`，推理使用 `appKey: OneChat`。账号信息、目录、额度与订阅查询，以及直连 `auto` 模型的流式和非流式调用均成功。此次测试账号没有 `sgcookie`，无需为该修复重新导入凭据；真实网页登录及国内版推理未在此次验证中执行。
