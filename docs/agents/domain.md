# Domain Docs

## 探索代码前

本仓库采用 single-context 布局：

- 阅读根目录 `GLOSSARY.md`。
- 阅读 `docs/adr/` 中与当前工作相关的架构决策。

文件不存在时直接继续；由 domain-modeling 技能在术语或决策确定后按需创建。

## 使用领域术语

任务标题、重构方案、假设和测试名称使用 GLOSSARY.md 定义的术语。

所需概念尚未收录时，判断是否沿用项目已有术语；确有缺口则记录给 domain-modeling。

## 决策冲突

方案与已有 ADR 冲突时，明确指出对应 ADR、冲突内容及重新讨论的理由。
