# Triage Labels

本地任务的 `Status:` 使用以下映射。

| 技能角色 | 本地状态 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由代理独立实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

技能要求设置 triage 标签时，将对应状态写入任务的 Status 行。
